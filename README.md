# 📝 4/10 Task Tracker (ระบบติดตามงาน บ.จ. ๓)

Web Application สำหรับนักเรียนและคุณครูโรงเรียนบรรหารแจ่มใสวิทยา ๓ (มัธยมศึกษาปีที่ 4 ห้อง 10) เพื่อช่วยในการจัดการ ติดตาม และตรวจสอบการส่งงานค้าง ออกแบบมาให้ใช้งานง่าย สีสันสดใส รองรับการใช้งานบนสมาร์ทโฟน (Mobile-First) และสามารถเปลี่ยนระดับชั้นเมื่อเลื่อนชั้นปีได้ (เช่น เลื่อนเป็น ม.5/10 ในปีการศึกษาถัดไป)

## 🌟 ฟีเจอร์เด่น (Features)

1. **🔄 สลับได้ 2 โหมด (Dual-Mode)**:
   - **โหมดนักเรียน (Student Mode)**: นักเรียนเลือกชื่อ/เลขที่ตนเองเพื่อดูเฉพาะงานที่ตนเองยังไม่ส่ง ติ๊กส่งงานแล้วมี Confetti 🎉 ฉลองความสำเร็จ
   - **โหมดครูผู้สอน / หัวหน้าห้อง (Teacher Mode)**: ตารางเช็คงานรายคน (Roster Matrix) ติ๊กส่งงานทีละคนหรือทั้งห้องแบบ Real-time
2. **📢 ทวงงานผ่าน LINE กลุ่มในคลิกเดียว**:
   - ปุ่มคัดลอกรายชื่อเพื่อนที่ยังไม่ส่งงาน พร้อมข้อความสรุปวิชา วันที่ส่ง และจัดรูปแบบสวยงามสำหรับวางใน LINE กลุ่มห้อง
3. **📊 Dashboard อัจฉริยะ**:
   - สรุปตัวเลขงานทั้งหมด, งานค้างส่ง, งานด่วน/ใกล้กำหนด, และงานที่ส่งแล้ว
   - การ์ดสรุปแยกตามรายวิชา
4. **📅 ปฏิทินกำหนดส่งงาน (Calendar View)**:
   - ปฏิทินรายเดือนภาษาไทย พร้อมพุทธศักราช (พ.ศ.)
   - แตะวันที่เพื่อตรวจดูงานที่ต้องส่งในวันนั้น
5. **📈 หน้าสถิติและความคืบหน้า (Statistics)**:
   - แผนภูมิวัดอัตราความสำเร็จทั้งห้อง
   - สถิติแยกตามรายวิชา
   - อันดับนักเรียนที่มีความรับผิดชอบส่งงานสูงสุด (Star Students)
6. **⚙️ การเลื่อนระดับชั้น (Promotion) & สำรองข้อมูล**:
   - ปรับเปลี่ยนระดับชั้นเรียนได้ทันที (ม.4/10 ➡️ ม.5/10 ➡️ ม.6/10)
   - Export ข้อมูลเป็น JSON เพื่อแชร์ให้เพื่อนร่วมห้อง Import ไปใช้งานได้โดยไม่ต้องกรอกใหม่

## 🛠️ วิธีการรันโปรเจกต์ (Getting Started)

### ความต้องการของระบบ (Prerequisites)
* Node.js (v18 ขึ้นไป) และ npm

### การรันในเครื่อง (Local Development)

```bash
# 1. ติดตั้ง Dependencies (ทำครั้งแรก)
npm install

# 2. เริ่มต้นรัน Dev Server
npm run dev
```

เปิดเบราว์เซอร์แล้วไปที่: [http://localhost:3000](http://localhost:3000)

### การ Build สำหรับ Production

```bash
npm run build
npm run start
```

### การ Deploy ขึ้น Vercel
1. อัปโหลดโค้ดขึ้น GitHub Repository
2. เข้าสู่ [Vercel](https://vercel.com) และกด "Import Project"
3. เลือก Framework Preset: **Next.js** และกด **Deploy** ได้ทันทีโดยไม่ต้องตั้งค่า Environment เพิ่มเติม!
